肘击大乱斗 · Windows 图形化服务器启动器
Elbow Mayhem

适用系统：Windows 10/11 x64。请完整解压 ZIP，再双击“肘击大乱斗启动器.exe”。
不要单独复制 EXE：它需要同目录下的 GameServer 文件夹。

1. 在“游戏服务器”页选择可用端口（默认 3000），单击“启动服务器”。
2. 窗口提示运行中且网页、Socket.IO 检查通过后，单击“打开游戏”。
3. 局域网内其他设备使用窗口中显示的实际局域网地址。防火墙可能需要用户自行允许入站访问。
4. “停止服务器”只停止启动器创建的游戏服务；“重启服务器”会在同一端口重新启动。
5. GameServer/config.json 可以设置 bindAddress（默认 0.0.0.0）和 maxRooms。端口由启动器选择并写入此配置。

SakuraFrp 公网联机：
启动器会检测本机已有 SakuraFrp 客户端，并使用其已有配置通过官方 API 读取隧道。
选择已有隧道后，核对本地目标端口；不一致时可点击“将游戏端口设为隧道目标”。
本机随 SakuraFrp Launcher 安装的 frpc.exe 明确仅允许 SakuraFrp Service 启动，故启动器中的隧道启停和自动启动按钮禁用。
请点击“打开 SakuraFrp 客户端”，在已有客户端中启动或停止选定隧道，然后返回启动器点击“刷新隧道”。
启动器不会安装客户端、新建或修改隧道，也不会停止原本由其他程序启动的隧道。
若官方 API 无法给出地址，可手动保存访问 URL；此地址会标为“用户配置，尚未验证”。
公网状态只有在网页、健康检查与 Socket.IO 轮询均成功时才显示已验证；这仍不等于远程设备完整对局验证。
SakuraFrp 访问密钥只在本机内存中用于官方接口和 frpc 环境变量，不会写入启动器日志或 ZIP。

公网访问需要已有隧道在线并能访问该端口。TCP 映射需使用节点域名与远程端口；
HTTP/HTTPS 映射使用配置的访问域名。不同网络的设备能否访问，还受节点、隧道、
防火墙和运营商网络条件影响。对外分享房间码时请只分享可信联系人。

日志位于 logs/launcher.log。出现启动失败时请先核对端口、GameServer 文件、配置和日志。
本包内含 Node.js 运行时与生产网页、Socket.IO 服务，无需安装 Node.js、npm、Vite 或 Python。
图形启动器基于 Windows .NET Framework 4.x；若系统禁用或移除此 Windows 组件，需要启用它。
