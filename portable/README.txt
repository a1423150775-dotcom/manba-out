肘击大乱斗 · Elbow Mayhem · 便携式游戏服务器

Windows 10/11 x64 启动
1. 将整个 ElbowMayhem 文件夹解压到任意位置。路径可以包含中文和空格。
2. 双击 start.bat。看到“服务器启动成功”后，在本机浏览器打开屏幕显示的 http://localhost:3000/?mode=realtime。
3. 若需局域网联机，先将config.json的bindAddress明确改为0.0.0.0再启动；同一局域网里的朋友使用屏幕显示的实际局域网 IP 地址和端口访问，然后输入房间码加入。
4. 双击 stop.bat 可以安全停止此便携包的服务器，也可以在启动窗口按 Ctrl+C。stop.bat 不会按进程名结束其他 Node 程序。
5. 若启动失败，窗口会保留错误提示。检查 config.json、端口占用和 logs/server.log。
6. 所有玩家请使用同一最新版本。收到新版 ZIP 后重新解压，浏览器按 Ctrl+F5 刷新；若页面提示发现新版本，点击刷新。访问地址后添加 ?debug=1 可查看连接状态、当前玩家及最近操作 ACK；诊断面板不显示身份令牌。

比赛操作
实时入口支持自由乱斗、MOBA、城堡攻防和Bot席位，技能按能量与前摇限制。Legacy入口 / 保留旧回合制。以下为Legacy操作：普通回合默认无限时，玩家主动结束个人回合。若大家想提前结束整场比赛，任意玩家可发起“结束本局”投票；全部参赛玩家同意后按当前累计积分结算，拒绝则继续，投票期间仍可正常行动。房主可二次确认关闭整个房间，所有人返回大厅，不产生比赛结果。比赛正常或投票结束后可查看排名、耗时并重新开局。

配置
config.json 中 port 默认 3000；如端口被占用，可改为 1～65535 中的空闲端口。
maxRooms 是内存房间数量上限，默认 100，允许 1～1000。
bindAddress 默认 127.0.0.1，仅本机可访问；显式改为 0.0.0.0 后允许局域网设备访问。
修改配置后先停止服务器，再重新启动。服务器不要求系统安装 Node.js、npm 或开发工具，也不需要管理员权限。

局域网与公网
同一局域网内，其他设备必须能连接运行服务器的电脑；操作系统防火墙可能需要用户自行允许 GameServer.exe 的入站 TCP 端口。此程序不会自动修改防火墙或路由器。访客网络、客户端隔离或不同网段也可能阻断连接。
不同网络的朋友不能仅靠房间码直接访问。公网模式需要把程序运行在有公网可达 IP/域名的主机上，或由用户自行配置可信的网络穿透服务。若主机位于运营商 CGNAT 或路由器 NAT 后，通常还需运营商公网地址和路由器端口转发；仅开放本机防火墙不够。
面向公网建议使用 HTTPS 反向代理，配置有效证书，并把 /socket.io/ 的 WebSocket Upgrade 正确转发，使浏览器使用 WSS。公网实际地址、域名和证书必须由部署者提供，本包不会自动创建。请限制允许访问的人、定期更新软件，并避免把 data/control.json 或 logs 目录通过网页共享。

安全与数据
服务端验证游戏操作；房间码不是身份凭证，每位玩家的身份令牌只保存在其浏览器会话中。logs/operations.log 记录请求 ID、玩家 ID、操作 ACK 与拒绝原因，供客户端诊断面板对应查找，不记录令牌；logs/server.log 记录启停状态。调试接口在生产包中禁用；停止控制仅监听本机回环接口并使用随机凭据。房间保存在内存中，服务器关闭或异常退出后，进行中的比赛无法恢复。

目录
GameServer.exe  自带的运行时（Windows 包）
server.cjs      已打包的服务端、Socket.IO 和规则引擎
web/            已构建的游戏网页
data/           本机停止控制记录
logs/           服务器状态日志
NODE_LICENSE.txt 和 THIRD_PARTY_NOTICES.txt  运行时与打包依赖的许可信息

Linux/macOS 包使用 ./start.sh 和 ./stop.sh；必须选择与操作系统及 CPU 架构相符的 ZIP。其他平台包若未在对应系统上测试，不应视为已验证兼容。
